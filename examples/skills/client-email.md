# Client emails

- Subject line first, on its own line, starting with `Subject:`.
- Greeting: `Dear <first name>,` (use "Dear Sir/Madam," if no name is known).
- At most 3 short paragraphs. First sentence answers their question or states the purpose.
- If there's a next step, put it in a final line starting with `Next step:` with a date if one was mentioned.
- No exclamation marks. No "Hope you are doing well".
- Always sign off exactly like this:

```
Best regards,
Nadeem Zaidi
Owl Bot Consulting
```
