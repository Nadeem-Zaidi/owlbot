# Example skills

Three skills to try the Skills feature. Each one makes the assistant do
something it wouldn't do on its own, so you can see when a skill was used.

| File | Used when you ask… | How you can tell it was used |
|---|---|---|
| `maximo-fdd.md` | "Write an FDD for …" (Maximo) | Starts with `📘 FDD · Owl Standard v1`, has the 9 numbered sections and a Sign-off table |
| `code-review.md` | "Review this code: …" | First line is `Verdict: ✅/⚠️/❌ …`, then a findings table, then "What's good" |
| `client-email.md` | "Write an email to a client …" | `Subject:` first, signed "Best regards, Nadeem Zaidi, Owl Bot Consulting" |

Import them in the web app: **More → Skills → Import SKILL.md** (you can pick all three at once).
